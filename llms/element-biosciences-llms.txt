# Element Biosciences

> Element Biosciences builds benchtop DNA sequencing and multiomics instruments — AVITI, AVITI LT, AVITI24 and VITARI — based on its Avidite Base Chemistry (ABC). Instrument data is managed in ElemBio Cloud, which exposes a public, versioned, read-only REST API and a first-party CLI for runs, workflow executions, instruments, storage connections and files.

## APIs

- [Element Biosciences Cloud API](https://docs.elembio.io/developers/api/): Read-only REST access to sequencing and multiomics runs, workflow executions, registered instruments, storage connections and their files. Base URL https://cloud-api.usw2.elembio.io, all paths under /v1. 16 operations, all GET.

## Authentication

Every request carries a static API key in the `x-api-key` header. Keys are created in
the ElemBio Cloud console under Organization > API Keys, expire after 1-365 days
(default 30), and carry explicit permissions of the form `resource:action[:resource_id]`
— `Runs:Read`, `Runs:Download`, `Executions:Read`, `Executions:Download`,
`Executions:Logs`, `Instruments:Read`, `Storage:Read`, `Storage:Download`. A request
that is authenticated but under-scoped returns HTTP 403 with reason `INSUFFICIENT_SCOPE`.
Call `GET /v1/auth` to see a key's tenant and scopes. There is no OAuth 2.0 flow.

## Conventions

- Pagination is cursor based: `pageSize` (default 100, max 1000), `pageToken`, `includeTotalCount`; the response carries `nextPageToken`.
- Filtering uses one keyword expression language on the `filter` parameter: `status:completed type:sequencing`, `time_completed>=7d`, `status:completed,failed`.
- Response bodies use lowerCamelCase; filter keywords use snake_case dotted paths.
- Timestamps are RFC 3339.
- Errors return `{code, message, details[]}` where `details[].reason` is the machine-readable code (`RUN_NOT_FOUND`, `INVALID_API_KEY`, `MISSING_API_KEY`, `INSUFFICIENT_SCOPE`, `INTERNAL_ERROR`). This is a google.rpc envelope, not RFC 9457 problem+json.
- `X-Request-ID` on the response correlates with `details[].metadata.request_id`; quote it to support.
- File downloads do not stream through the API. The `*/credentials` operations vend short-lived scoped AWS S3 session credentials for direct S3 access.
